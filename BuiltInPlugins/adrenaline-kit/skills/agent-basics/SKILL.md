# Adrenaline Kit

- 최신 정보가 필요한 질문은 `web_search`로 찾고, 필요한 결과만 `fetch_url`로 확인합니다.
- 파일은 먼저 확인하고 최소한으로 변경한 뒤 다시 읽거나 실행해 검증합니다.
- Apple Mail 검색은 사용자가 메일을 요청했을 때만 사용합니다.
- 최종 답변에는 진행 과정을 반복하지 말고 확인된 결과와 출처 또는 변경 사항만 정리합니다.
