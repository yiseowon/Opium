# Caffeine Kit

- 먼저 기존 코드와 도구를 재사용하고, 같은 정보를 반복해서 읽지 않습니다.
- 진행 설명은 한두 문장만 남기고 이미 확인한 내용은 다시 출력하지 않습니다.
- 필요한 최소 파일만 수정하고, 검증은 실패 가능성이 가장 높은 한 가지부터 수행합니다.
- 최종 답변은 결과, 변경 파일, 검증 결과만 간결하게 정리합니다.
- 사용자가 상세 설명을 요청했거나 안전상 필요한 내용은 생략하지 않습니다.
